     1→     1→# SoNovel — Tài liệu giao việc (Spec dựng lại từ đầu) cho z.code
     2→     2→
     3→     3→> Mục tiêu: dựng **toàn bộ** ứng dụng nghe truyện "SoNovel" (Vietnamese audiobook/story-listening app) từ con số 0, theo đúng spec dưới đây. Đây là tài liệu tự chứa (self-contained) — không cần repo cũ, nhưng nếu có repo cũ thì code mới phải tương đương về tính năng.

     7→     7→## 1. Tổng quan dự án
     8→     8→
     9→     9→SoNovel là app **đọc + nghe truyện chữ** (truyện Trung Quốc/Việt được nhập nội dung chữ) bằng **giọng đọc tổng hợp (TTS)**. Không có file audio được render sẵn — toàn bộ audio là **TTS client-side, phát trực tiếp**:
    10→    10→
    11→    11→- `web` + `admin-web`: dùng **Web Speech API** (`speechSynthesis`) của trình duyệt.
    12→    12→- `mobile` (Android): dùng **Android system TTS engine** thông qua native module Kotlin `sonovel-tts`.
    13→    13→
    14→    14→Toàn bộ dữ liệu qua **Supabase (Postgres + RLS + Auth + Storage)** bằng REST. **KHÔNG có backend Node/Express riêng.**
    15→    15→
    16→    16→Giao diện người dùng: **tiếng Việt hoàn toàn** (mọi chuỗi UI, lỗi, toast…). Font ưu tiên **Be Vietnam Pro**.

    65→    65→## 5. Backend — Supabase
    66→    66→
    67→    67→### 5.1 Auth
    68→    68→- **Chỉ email/password** (`signInWithPassword` / `signUp`). Không OAuth, không magic link, không UI reset password.
    69→    69→- Tự tạo `profiles` khi đăng ký (trigger trên `auth.users`).
    70→    70→- Phân quyền **admin** qua `profiles.role` (`user`/`admin`); helper `public.is_admin()` security definer.
    71→    71→
    72→    72→### 5.2 Bảng dữ liệu (đầy đủ cột, ràng buộc)
    73→    73→
    74→    74→**`profiles`**
    75→    75→- `id uuid PK → auth.users(id) on delete cascade`
    76→    76→- `role text default 'user' check (role in ('user','admin'))`
    77→    77→- `created_at timestamptz default now()`
    78→    78→
    79→    79→**`series`** (bộ truyện)
    80→    80→- `id uuid PK default gen_random_uuid()`
    81→    81→- `title text not null`
    82→    82→- `author text not null default ''`
    83→    83→- `description text not null default ''`
    84→    84→- `cover_url text not null default ''`
    85→    85→- `status text not null default 'published' check (status in ('draft','published','completed','hidden'))`
    86→    86→- `genres text[] not null default '{}'`
    87→    87→- `tags text[] not null default '{}'`
    88→    88→- `word_count integer not null default 0` (tổng từ của các chương published — migration 004)
    89→    89→- `created_at timestamptz not null default now()`
    90→    90→- `updated_at timestamptz not null default now()`
    91→    91→
    92→    92→**`chapters`**
    93→    93→- `id uuid PK default gen_random_uuid()`
    94→    94→- `series_id uuid not null → series(id) on delete cascade`
    95→    95→- `order_no integer not null`
    96→    96→- `title text not null`
    97→    97→- `content text not null default ''` (chính là văn bản app sẽ đọc)
    98→    98→- `status text not null default 'published' check (status in ('draft','published'))` ← **CHỈ 2 trạng thái**
    99→    99→- `published_at timestamptz`
   100→   100→- `word_count integer not null default 0`
   101→   101→- `created_at timestamptz not null default now()`
   102→   102→- `unique (series_id, order_no)`
   103→   103→
   104→   104→**`progress`** — 2 track ĐỌC và NGHE (dual-track):
   105→   105→- `id uuid PK default gen_random_uuid()`
   106→   106→- `user_id uuid not null → auth.users(id) on delete cascade`
   107→   107→- `series_id uuid not null → series(id) on delete cascade`
   108→   108→- Track ĐỌC: `read_chapter_id uuid → chapters(id) on delete set null`, `read_char_index int default 0`, `read_percent numeric default 0`, `last_read_at timestamptz`
   109→   109→- Track NGHE: `listen_chapter_id uuid → chapters(id) on delete set null`, `listen_char_index int default 0`, `audio_sec numeric default 0`, `playback_speed numeric default 1.0`, `last_listened_at timestamptz`
   110→   110→- `updated_at timestamptz default now()` (trigger `set_updated_at`)
   111→   111→- `unique (user_id, series_id)`
   112→   112→
   113→   113→**`favorites`** — `user_id + series_id` PK, `created_at`.
   114→   114→
   115→   115→**`bookmarks`** — `id, user_id, series_id, chapter_id, char_index int default 0, note text default '', created_at`.
   116→   116→
   117→   117→**`history`** — `user_id + series_id` PK, `opened_count int default 1`, `last_opened_at timestamptz`.
   118→   118→
   119→   119→**`user_settings`** — `user_id PK → auth.users`, `theme text default 'light' check (theme in ('light','dark','sepia','amoled'))`, `playback_speed numeric default 1.0`, `font_size int default 18`, `font_family text default 'system'`, `line_height numeric default 1.7`, `autoplay_next boolean default true`, `updated_at`.
   120→   120→
   121→   121→**`chapter_audio`** — `chapter_id PK → chapters(id) on delete cascade`, `audio_url text default ''`, `duration_sec numeric default 0`, `created_at`. *(dự phòng cho phase sau — hiện chưa dùng)*
   122→   122→
   123→   123→**`tags`** (master, quản lý tập trung) — `id uuid PK`, `name text unique not null`, `created_at`. Seed 15 tag mặc định: hệ thống, xuyên không, sảng văn, ngôn tình, kiếm hiệp, tiên hiệp, đô thị, huyền huyễn, đồng nhân, dị giới, võng du, trọng sinh, làm ruộng, xây dựng, tình cảm.
   124→   124→
   125→   125→### 5.3 RLS policies
   126→   126→- `profiles`: select public; insert/update bởi chính chủ (`auth.uid() = id`).
   127→   127→- `series`: select public (true); insert/update/delete chỉ khi `is_admin()`.
   128→   128→- `chapters`: select public; insert/update/delete chỉ `is_admin()`.
   129→   129→- `progress`, `favorites`, `bookmarks`, `history`, `user_settings`: mọi thao tác chỉ chủ sở hữu (`auth.uid() = user_id`).
   130→   130→- `tags`: select public; write chỉ `is_admin()`.
   131→   131→- `chapter_audio`: select public.
   132→   132→- Storage `covers`: select public; write chỉ `is_admin()`.
   133→   133→
   134→   134→### 5.4 Storage
   135→   135→- Bucket **`covers`** public (`id='covers'`, public=true) — chứa ảnh bìa. Policy: select public, insert/update/delete admin.
   136→   136→
   137→   137→### 5.5 Hàm & trigger
   138→   138→- `handle_new_user()` — trigger `on_auth_user_created` trên `auth.users`: tự tạo `profiles`.
   139→   139→- `is_admin()` — security definer: `exists(profiles where id=auth.uid() and role='admin')`.
   140→   140→- `set_updated_at()` — trigger trước UPDATE trên `progress`, `user_settings`, `series`: set `updated_at=now()`.
   141→   141→- `ensure_user_settings()` — trigger sau INSERT `progress`: tự tạo hàng `user_settings` nếu chưa có.
   142→   142→- `recalc_series_word_count(series_uuid)` + trigger `chapters_sync_word_count` sau INSERT/UPDATE/DELETE `chapters`: tính lại `series.word_count = sum(length(content)/5)` cho các chương `published`.
   143→   143→
   144→   144→### 5.6 Seed mẫu
   145→   145→- 3 bộ truyện mẫu (id cố định `00000000-...-0001..0003`) + 8 chương mẫu.
   146→   146→- Không bắt buộc; dùng để test luồng nghe.
   147→   147→- Gán admin: `update public.profiles set role='admin' where id='<USER_ID>'` (lấy UUID trong Authentication → Users).
   148→   148→
   149→   149→### 5.7 Thứ tự áp dụng
   150→   150→1. `schema.sql` → 2. `migrations/002_expand.sql` → 3. `migrations/003_tags.sql` → 4. `migrations/004_word_count.sql`. (Với Supabase CLI: `supabase migration repair --status applied 002 003` rồi `supabase db push` nếu 002/003 đã chạy tay qua SQL Editor.)

   181→   181→- Guard admin. Liệt kê `tags` sort theo tên.
   182→   182→- Thêm (input + button, trùng name → lỗi inline). Sửa inline (Enter lưu, Escape hủy, empty → hủy). Xóa (Confirm, ghi chú: không ảnh hưởng series đang dùng tag).

   193→   193→
   194→   194→**Trang:**
   195→   195→
   196→   196→- **Home** `/`: 1 query toàn catalogue `series` (`status IN ('published','completed')`, order `updated_at desc`, select `*, chapters(count)`), tự suy 3 section: "Truyện mới cập nhật" (top 10), "Phổ biến" (sort theo `chapters(count)` desc, top 10), "Thể loại" (12 genre chips → `/search?genre=`). Hero + CTA. **Continue listening**: progress người dùng (listen columns), lọc có `listen_chapter_id` hợp lệ, top 5, thẻ hiện bìa + "Chương X · còn ~N phút" + progress bar + nút play → tải chapters published → `playChapter({index, startChar: listen_char_index})`.
   197→   197→- **Search** `/search`: query params `q`/`genre`/`tag`, debounce 350ms ghi lại URL. **Recent searches** `localStorage['sonovel-recent-searches']` max 8. Facet chips (genres + tags từ tối đa 500 series). Kết quả: `ilike` title/author, `contains` genres/tags, sort `new` (updated_at desc)/`title`/`chapters` (word_count desc), **phân trang 24/trang**.

Status badge, genre/tag chips, description. Danh sách chương: filter title/order, từ đếm `word_count`, phút nghe ước tính, click → play; chương hiện tại 🔊, chương đã nghe 🎧 %.

   200→   200→- **History** `/history`: gate đăng nhập. `history` join `series` order `last_opened_at desc` limit 20. Label "time ago".

   281→   281→### 8.5 Native TTS module — **PHẦN DỄ SAI NHẤT, ĐÃ TỐN NHIỀU VÒNG SỬA. ĐỌC KỸ.**
   282→   282→
   283→   283→**Kiến trúc:**
   284→   284→- `TtsService.kt`: **foreground service** (`foregroundServiceType="mediaPlayback"`) — phát nền khi khóa màn hình/ra nền. **MediaSession** + **notification** (prev / play-pause / next / stop) điều khiển được từ màn hình khóa + notification drawer.
   285→   285→- `TtsChunker.kt`: chia content thành chunk **~900 ký tự** tại biên câu/đoạn (`TtsChunker.chunk(content)`), `findChunkIndex(chunks, charIndex)`.
   286→   286→- `SonovelTtsModule.kt`: `AsyncFunction`: `play(seriesTitle, coverUrl, chaptersJson, startChapterIndex, startCharIndex, rate)`, `playChapter(idx, startChar)`, `pause`, `resume`, `stop`, `seekTo(char)`, `setRate(r)`, `nextChapter`, `prevChapter`, `getState()`, `requestNotificationPermission()`. `Events`: `onStateChange` (playing/paused/stopped), `onProgress`, `onChunkDone`, `onChapterEnd`, `onChapterChange`, `onSeriesEnd`, `onError`.
   287→   287→- Manifest module: `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MEDIA_PLAYBACK`, `POST_NOTIFICATIONS` (+ queries `TTS_SERVICE`). Chạy trên Android 14+ phải đủ permission, nếu thiếu `FOREGROUND_SERVICE_MEDIA_PLAYBACK` → `startForeground` ném `SecurityException` → service chết.
   288→   288→- `TtsService.module` (companion) được set trong `OnCreate`/`OnDestroy` của module; mọi lệnh JS gọi qua static companion `main.post { instance?.onXxx() }` (chạy trên main thread).
   289→   289→
   290→   290→**Luồng phát:**
   291→   291→- `play()` → `ContextCompat.startForegroundService` với `ACTION_START` + extras → `onStartCommand` parse chapters, `startForegroundNow()`, `requestAudioFocus()`, `ensureTts { playFrom(charIndex) }`.
   292→   292→- `ensureTts`: nếu `ttsReady` → gọi ngay; nếu chưa → lưu `pendingPlay`, gọi `initTts()` (tạo `TextToSpeech`), chờ `onInit`.
   293→   293→- `onInit(SUCCESS)` → set `ttsReady=true`, cấu hình audio attributes `USAGE_MEDIA`/`CONTENT_TYPE_SPEECH`, language **vi-VN** (nếu thiếu → fallback locale mặc định + `onError` code 1 "Thiếu giọng tiếng Việt"), `setSpeechRate`, `setOnUtteranceProgressListener`, rồi `pendingPlay?.invoke()`. `onInit(ERROR)` → **reset `tts=null` + `pendingPlay=null`** + emit onError code 0.
   294→   294→- `playFrom(targetChar)`: coerce vị trí, đọc tiêu đề chương khi bắt đầu (`announceTitle && clamped==0`), chia chunk, `tts?.speak(text, QUEUE_FLUSH, params, chunkId)`. Mỗi utterance có id **DUY NHẤT** `sonovel_${chapterIndex}_${chunkIdx}_${++speakSeq}` (hoặc `sonovel_title_...`).
   295→   295→
   296→   296→**Các bug đã từng gặp — bắt buộc xử lý đúng (đừng tái phạm):**
   297→   297→1. **Resume sau pause bị "im lặng"** — Android TTS hay **"nuốt" speak() gọi ngay sau stop()**. Fix đã áp dụng:
   298→   298→   - **JS không còn dựa vào native resume()**. `resumePlayback()`: native đang `playing` → chỉ sync UI; còn lại → **luôn `startTts()` khởi động lại hoàn toàn từ vị trí đang nhớ** (con đường `ACTION_START` đáng tin cậy nhất — phát lần đầu luôn chạy).
   299→   299→   - Native `onResume` (notification play) giữ `SETTLE_MS=200` trễ một nhịp trước khi speak sau stop.
   300→   300→2. **Callback lạc/trùng** — onDone/onError trễ của utterance bị pause tái sử dụng id → tưởng là utterance mới. Fix: **`speakSeq` tăng dần** để id luôn duy nhất; mọi callback (`onStart`/`onRangeStart`/`onDone`/`onError`) **guard `if (utteranceId != currentUtteranceId) return`**. `onStateChange 'playing'` chỉ phát từ `onStart` THẬT.
   301→   301→3. **Watchdog chống "im lặng"**: mỗi `playFrom` schedule watchdog `WATCHDOG_MS=2000`; nếu speak trả OK mà engine không `onStart` → retry `MAX_RETRY=2` lần (`ensureTts { playFrom(pendingTargetChar) }`), sau đó **re-init engine** (`tts.shutdown()` + tạo mới), hết cách → `onErrorInternal` báo lỗi rõ ràng.
   302→   302→4. **Init timeout**: `initTts()` arm timeout `INIT_TIMEOUT_MS=6000`; nếu engine **không bao giờ gọi `onInit`** (binding/hang sau shutdown) → tự emit `onError` (không treo mãi).
   303→   303→5. **JS safety net**: `startTts()`/`playChapterTts()` set `busy=true` + arm timeout **12 giây**; nếu native im lặng (không `onStateChange`/`onProgress`/`onError`) → tự xoá busy + `stop()` service + emit error. → **NÚT PLAY KHÔNG BAO GIỜ XOAY MÃI.**
   304→   304→6. `playFrom` khi `!ttsReady` không được return im lặng — phải nối qua `ensureTts` (return im lặng làm watchdog mất dấu → treo).
   305→   305→
   306→   306→**JS `tts.ts` (state manager):**
   307→   307→- Biến global module: `seriesId, seriesTitle, coverUrl, chapters[], currentIndex, currentChar, rate, isPlaying, busy, seriesEnded`.
   308→   308→- Hàm: `getNowPlaying()` (snapshot), `startTts(opts)`, `playChapterTts(idx, startChar)`, `pauseTts()`, `resumePlayback()`, `togglePlayPause()` (đang phát→pause; busy→stop; còn lại→resumePlayback), `stopTts()`, `seekToTts`, `setRateTts`, `nextChapterTts`, `prevChapterTts`, `flushTtsSave`, `getTtsState()`, `onTtsEvent(type, cb)`.
   309→   309→- Lắng nghe events native → cập nhật state + emit local events (`stateChange`, `progress`, `chunkDone`, `chapterEnd`, `chapterChange`, `seriesEnd`, `error`, `nowPlaying`).
   310→   310→- **Lưu tiến độ**: `scheduleSave()` throttle 4 giây (mỗi lần phát 1 timer), `flushTtsSave()` upsert `progress` (listen track: `listen_chapter_id`, `listen_char_index`, `playback_speed`, `last_listened_at`) — **chạy cả khi app ở nền** (foreground service phát tiếp). Bỏ qua nếu chưa đăng nhập / lỗi mạng.
   311→   311→- Rate lưu `AsyncStorage['sonovel.playbackRate']`.
